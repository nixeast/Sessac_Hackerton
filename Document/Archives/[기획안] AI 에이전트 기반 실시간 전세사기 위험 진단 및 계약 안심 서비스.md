# [기획안] AI 에이전트 기반 실시간 전세사기 위험 진단 및 계약 안심 서비스
**서비스명(가칭):** SafeRent AI (안심전세 에이전트)

---

## 1. 기획 배경 및 목적

### 1.1 배경
* **청년층 전세사기 피해 심화:** 주택 거래 경험이 적고 부동산 법률·권리 분석 지식이 부족한 사회초년생 및 2030 청년층이 갭투자, 선순위 근저당, 깡통전세 등 전세사기 표적이 되고 있습니다.
* **기존 서비스의 한계:** 단편적인 시세 조회 앱이나 등기부등본 열람 서비스는 수치와 복잡한 용어만 제공할 뿐, **권리관계 간의 복합 추론**과 **즉각적인 계약 주의사항 제시**에 한계가 있습니다.

### 1.2 목적
* 등기부등본, 건축물대장, 시세 데이터, 집주인 체납 정보 등을 **AI Multi-Agent 구조**로 자율 수집 및 교차 검증합니다.
* 청년이 안심하고 계약할 수 있도록 **실시간 종합 위험도 리포트** 및 **계약 단계별 체크리스트/특약 문구**를 자동으로 도출해 제공합니다.

---

## 2. 핵심 Target User

* **주요 사용자:** 첫 독립 및 전·월세 계약을 앞둔 대학생, 취업준비생, 사회초년생 청년.
* **주요 니즈:**
  * 복잡한 부동산 등기부등본을 쉬운 언어로 해설받고 싶음.
  * 보증금을 안전하게 돌려받을 수 있는지(깡통전세 여부, 선순위 채권 등) 한눈에 확인하고 싶음.
  * 부동산 계약서에 들어가야 할 필수 보호 특약 문구를 자동으로 작성받고 싶음.

## 3. 서비스 핵심 기능 (System Core)

| 기능 분류 | 세부 기능 | 설명 |
| :--- | :--- | :--- |
| **1. 문서 OCR & 자동 파싱** | 등기부등본 / 건축물대장 분석 | 업로드된 PDF/이미지에서 갑구(소유권), 을구(근저당·가압류 등), 위반건축물 여부 자동 추출 |
| **2. 권리 및 시세 분석** | 깡통전세 & 선순위 채권 계산 | 실거래가 API 및 시세 데이터를 기반으로 **[근저당 + 선순위 보증금 + 내 보증금] / 매매 시세** 비율 산출 |
| **3. 위험도 산출 & 리포트** | 5단계 안전 지수 시각화 | 위험도(안전, 주의, 경고, 위험, 계약불가) 종합 판정 및 사유 브리핑 |
| **4. 맞춤형 특약 생성** | AI 특약 생성기 | 매물 특성에 맞춰 임차인 보호용 맞춤형 계약 특약 문구(보증보험 불가 시 계약 해제 등) 제안 |
| **5. 계약 가이드 & 체크리스트** | 현장 및 계약 당일 가이드 | 임대인 신분증 확인, 대리인 위임장 검증, 잔금 입금 전 등기 재확인 등 단계별 가이드 |

## 4. Multi-Agent 아키텍처 및 연동 API

```
                     [ 사용자 (매물 주소 / 보증금 / 등기부 PDF 입력) ]
                                            │
                                            ▼
                             ┌──────────────────────────────┐
                             │    Orchestrator Agent        │
                             │ (작업 분담 및 종합 판정)      │
                             └──────────────┬───────────────┘
                                            │
         ┌──────────────────────────────────┼──────────────────────────────────┐
         ▼                                  ▼                                  ▼
┌─────────────────┐                ┌─────────────────┐                ┌─────────────────┐
│ Document Parser │                │  Market Data    │                │  Risk Assessment│
│      Agent      │                │     Agent       │                │      Agent      │
└────────┬────────┘                └────────┬────────┘                └────────┬────────┘
         │                                  │                                  │
  • 등기부 OCR/파싱                  • 실거래가/시세 조회               • 보증금 변제순위 분석
  • 건축물대장 분석                  • 공시가격 조회                    • 보증보험 가입가능성
  • 위반건축물 확인                  • 임대인 체납여부 연동             • 전세가율 계산
         │                                  │                                  │
         └──────────────────────────────────┼──────────────────────────────────┘
                                            │
                                            ▼
                             ┌──────────────────────────────┐
                             │    Report & Action Agent     │
                             │ (리포트 생성 & 특약 문구 도출)│
                             └──────────────┬───────────────┘
```

### 연동 API 및 데이터 소스
1. **대법원 인터넷등기소 API / OCR 엔진:** 등기부등본 실시간 열람 및 갑구/을구 권리관계 추출
2. **국토교통부 실거래가 공개시스템 API:** 해당 단지/빌라 및 인근 유사 매물의 매매·전세 실거래가 조회
3. **정부24 (건축물대장 API):** 위반건축물 지정 여부 및 용도(근린생활시설 여부 등) 조회
4. **국세청 / 지자체 체납 정보 조회 API:** 임대인 국세·지방세 체납 여부 (동의 기반 조회)
5. **HUG / SGI 보증보험 가입 기준 데이터:** 전세보증금 반환보증 가입 가능 여부 판정 로직

## 5. 단계별 사용자 시나리오 (User Journey)

1. **입력 단계:**
   * 사용자가 탐색 중인 매물의 주소, 희망 전세 보증금, 계약 예정일을 입력 (발급받은 등기부등본 파일 첨부 시 즉시 분석).
2. **에이전트 분석 단계:**
   * **Document Agent**가 등기부상 근저당 설정액(채권최고액), 신탁 등기 여부, 압류/가압류 이력을 파악.
   * **Market Data Agent**가 해당 매물의 적정 시세를 추정하고 전세가율 계산.
   * **Risk Assessment Agent**가 [선순위 채권 + 보증금] 비율이 시세의 70%를 넘는지, 보증보험 가입 조건에 부합하는지 판단.
3. **결과 리포트 수령:**
   * "이 매물은 **전세가율 85%**로 **[주의]** 단계입니다. 근저당 1.2억 원이 설정되어 있어 보증금 일부를 돌려받지 못할 위험이 있습니다." 형태의 명확한 브리핑.
4. **대응 및 계약 실행 보조:**
   * AI가 "계약서 작성 시 반드시 추가해야 할 특약 3가지" 자동 생성 및 다운로드 제공.
   * *"임대인은 잔금 지급일 다음 날까지 등기부등본상 근저당권 등 새로운 권리를 설정하지 아니한다."* 등

## 6. 기대 효과 및 확장 가능성

* **청년 주거 안심망 형성:** 정보 비대칭으로 인한 사회초년생의 전세사기 피해 원천 차단.
* **사회적 비용 절감:** 사후 피해 구제에 소요되는 금융·법적 공공 자원 소모 예방.
* **서비스 확장성:** 
  * 공인중개사 자격 검증 기능 연동.
  * 청년 전세자금대출 매칭 알고리즘 통합.
  * 법률구조공단 또는 청년 주거 상담 전문 변호사와의 1:1 연계 플로우 구축.
